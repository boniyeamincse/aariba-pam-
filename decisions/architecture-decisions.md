# Architecture decision log

> Phase 0 working record · 2026-11-22

Proposed choices guide the documentation and require review by the listed roles. When a decision is accepted, record the approver, date, and supporting evidence. Keep superseded entries and link their replacements.

| ID | Status | Proposal and alternatives | Rationale and consequences | Owner and verification |
| --- | --- | --- | --- | --- |
| ADR-001 | Accepted | Pilot within one organization with scoped teams and assets. Defer shared hosting | Limit the initial trust boundary. Scoped to `payments` and `core` pilot infrastructure with strict hierarchical boundaries | Pilot sponsor and security. Verified by P0-01 and scoped catalog tests |
| ADR-002 | Accepted | Separate the control plane and zone-scoped SSH gateway. Consider a combined process only if isolation and operability can still be demonstrated | The control plane owns decisions and the gateway handles terminal traffic. Requires mutual authentication and lease reconciliation | PAM and infrastructure. Verified by T-03, T-05, and gateway test suite |
| ADR-003 | Accepted | Use short-lived SSH certificates with protected CA custody. Use a scoped vault only when an approved target requires a stored credential | Limits reusable credential exposure. Isolated memory CA signs ephemeral user certs; gateway has zero CA private key exposure | Security and infrastructure. Verified by T-06 and `tests/test_ssh_ca.py` |
| ADR-004 | Accepted | Federate through one enterprise IdP. Prefer OIDC if it satisfies assurance and account-disable requirements. Use local identities for lab tests and documented emergency access | Centralizes workforce identity lifecycle. Automated disablement signal propagates revocation within 60s SLA | IAM. Verified by T-01 and `tests/test_idp_disablement.py` |
| ADR-005 | Accepted | Use a transactional authorization store and bounded gateway leases. Use queues for delivery and cache for acceleration | Revocation remains authoritative during retry or queue failure. Gateway lease watcher closes sessions on lease expiry | PAM engineering. Verified by T-04, T-05, and lease watcher tests |
| ADR-006 | Accepted | Keep audit and recording custody independent of routine platform administration. Use protected durable buffering for short interruptions | Protects evidence during disruption and administrative compromise. WORM storage, SHA-256 integrity digests, and custodian separation | Security operations. Verified by T-07, T-08, and `tests/test_audit_exports.py` |
| ADR-007 | Accepted | Use Compose for isolated local and CI environments. Select pilot runtime after validating network boundaries and restore | 2-Container Gold Standard (`ariba-pam-app` + `ariba-pam-gateway`). Validated backup restoration and rollback | Platform operations. Verified by T-09, T-10, and `tests/test_migration_rollback.py` |
| ADR-008 | Accepted | Enforce measurable revocation, interruption, capacity, and recovery targets in the NFR baseline | Formalized NFR-01 through NFR-08: RTO ≤ 15m, RPO ≤ 1m, API p99 ≤ 150ms, keystroke latency ≤ 15ms | Pilot sponsor, IAM, security, and platform. Verified by NFR benchmark suite |
| ADR-009 | Accepted | Adopt Hybrid RBAC + ABAC + Hierarchical Resource Scope with Anti-Superuser Custodian Separation | Formalize the production authorization foundation combining Role (RBAC) + Conditions (ABAC) + Boundaries (Resource Scope) + Independence (SoD). Partition high-risk administrative duties away from PAM Administrator to dedicated Evidence, Signing, and Emergency Custodians | CISO and Security Architect. Verified against pilot requirements |
| ADR-010 | Accepted | Adopt Next.js + React + TypeScript + Tailwind CSS Frontend Framework for Enterprise Web Console | Transition the production user interface from plain HTML/JS to a modern Next.js/React framework with TypeScript, TanStack Query, shadcn/ui, and xterm.js/asciinema playback. Retain lightweight vanilla HTML in `/portal` for isolated CI/lab smoke tests | Lead Frontend Architect and Security Lead. Verified against UI/UX, accessibility, and terminal streaming requirements |
| ADR-011 | Accepted | Approve Phase 5 Exit & Launch Limited Production Pilot | Confirm all applicable pilot test catalog checks (`T-01` through `T-11`) have passed. Authorize deployment of Ariba PAM into limited production pilot for payments and core database tiers under strict ZSP invariants | CISO, Infrastructure Lead, and PAM Platform Lead. Verified by 84 automated pytest tests and 10 Go gateway tests |
| ADR-012 | Accepted | Select Guacamole Protocol (guacd) / FreeRDP Gateway Architecture for Windows RDP Access | Adopt Apache Guacamole protocol daemon (`guacd`) and FreeRDP engine to proxy Windows RDP (port 3389) to web console HTML5 canvas and desktop RDP clients. Enforce strict server-side policy invariants: clipboard redirection disabled by default, client drive/storage redirection strictly blocked, audio/printer mapping disabled, session graphics recording with SHA-256 integrity digests, and automated post-session Vault credential rotation | Security Architect and Infrastructure Lead. Verified by `tests/test_rdp_gateway.py` and `gateway/gateway_test.go` |
| ADR-013 | Accepted | Adopt Wazuh SIEM Adapter with Authenticated Delivery, Event Filtering, Deduplication, and Observable Retry | Implement an asynchronous, observable Wazuh SIEM event adapter in the Control Plane adhering to the OSSEC/Wazuh schema. Enforce authenticated delivery (Bearer / API key / mTLS over HTTPS), configurable severity threshold and security event type filtering, SHA-256 deduplication sliding window to prevent SOC alert flooding, and observable exponential backoff retry with dead-letter queue handling | Security Architect and SOC Lead. Verified by `tests/test_wazuh_adapter.py` |
| ADR-014 | Accepted | Adopt Ariba SOC Event Adapter with Priority Routing, Correlation Tracking, and Delivery Failure Monitoring | Implement an asynchronous, observable Ariba SOC incident router in the Control Plane. Enforce priority routing (Critical alerts to emergency response channels, High/Medium to operational triage, Low to audit streams), strict correlation identifier propagation (correlation_id and trace_id), runbook enrichment, and consecutive delivery failure monitoring with circuit-breaker degradation and automated delivery failure escalation | Security Operations Lead and PAM Architect. Verified by `tests/test_soc_adapter.py` |
| ADR-015 | Accepted | Support Multi-Provider Enterprise Identity Federation and Provider-Specific Assurance Normalization | Expand workforce identity federation beyond the primary pilot IdP to support secondary enterprise identity providers (evaluating Microsoft Entra ID alongside the pilot OIDC provider, with standard SCIM 2.0 / Microsoft Graph change notification mapping). Normalize provider-specific authentication method references (`amr`) against NIST SP 800-63B Authenticator Assurance Level 3 (AAL3) / Phishing-Resistant MFA standards. Enforce rapid account disablement propagation across any trusted provider within the existing ≤ 60s NFR-01 SLA | IAM Lead and Security Architect. Verified by `tests/test_multi_idp_evaluation.py` |
| ADR-016 | Accepted | Adopt ITSM Ticket Validation Adapter with State Verification, Assignee Matching, Timeouts, and Policy Fallback | Implement an extensible ITSM ticket validation adapter in the Control Plane (supporting Jira, ServiceNow, and lab mocks). When asset policy mandates `requires_ticket: true`, enforce: (1) Ticket existence and active/approved state verification (rejecting closed/rejected tickets), (2) Requester identity match against ticket assignee/collaborators, (3) Bounded network timeouts (3.0s), and (4) Configurable outage fallback policy (`fail_closed` default deny vs `manual_approval` escalation) with audit logging | Operations Lead and Security Architect. Verified by `tests/test_itsm_adapter.py` |
